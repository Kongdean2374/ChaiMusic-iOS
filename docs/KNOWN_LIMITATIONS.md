# 首版已知限制

## 尚未驗證

本次環境沒有 Xcode／Swift 工具鏈，GitHub CLI 授權無效且連接器沒有首次 Actions dispatch。沒有執行任何單元測試、Swift 編譯、iPhone 裝置編譯或實機操作。原始碼內存在未發現的編譯／執行期問題的可能；不能宣稱 P0 已驗收。

背景播放、中斷恢復、鎖定畫面、iPhone 17 Pro 安全區、VoiceOver、Dynamic Type、音檔解碼與音質欄位均需在 High／Medium 任務取得首份 IPA 後驗證。

## 功能與規模

- WebDAV、SMB、商業串流音源、外掛載入器、網路搜尋／同步、下載管理、音效、智慧電台、偏好隨機與無縫音質升級未完成。只有來源協定預留，不代表可連線。
- 沒有自動翻譯服務；LRC 支援逐行與 `<mm:ss.xx>` 增強逐字格式，未涵蓋所有廠商私有逐字歌詞格式。模型保留翻譯／語言／可信度欄位；未做翻譯匯入與編輯介面。
- 沒有授權動態封面；使用本機封面與原創漸層。首版未做封面取色動畫或低階解碼音質切換。
- 預設暗色，不提供未生效的外觀／音效開關。歌單基本新增與加減曲目已實作，尚無歌單重新命名／刪除／跨裝置同步。
- 同檔重複匯入會建立不同曲目 ID，沒有內容雜湊去重。Shuffle 會去除同一 ID 的重複，不能辨識不同檔案是否相同錄音。
- 播放中的來源集合是啟動該次佇列時的快照；歌單新增歌曲後需重新播放該歌單才納入。刪除歌曲會清理佇列，移出歌單不會立即移出既有播放快照。
- 統計每十秒保存，系統強制終止可能遺失最近最多約十秒進度／紀錄。跨日事件依起始日期分組，未分割午夜前後秒數。抵達尾端不等於完整收聽，應同時看實際秒數與完成比例。
- 原子 JSON 寫入仍在主執行緒執行，大量歌曲與長期歷史可能造成延遲；未做無限規模效能或資料庫遷移。資料匯出不包含音檔，沒有完整還原／自動備份。
- 遺失或不能播放的檔案顯示錯誤並停止；不會在背景無限跳過與重試。

## 建置

公開儲存庫標準 runner 的可用性、Actions 執行權限及 artifact 額度由 GitHub 政策決定。未簽署建置不需要 Apple 憑證；本次沒有簽署、TestFlight、App Store Connect 或安裝工作。

CI 必須成功通過裝置平台／架構／Bundle 驗證後才會有 IPA Artifact；原始碼 ZIP 不是 IPA，不能更名冒充。
