# V2 差距與已知限制

## 仍待 Apple 平台驗收

42 個 Linux Swift 核心／SQLite／備份測試與 fixture 協定測試通過，不等於整個 iOS App 已編譯。所有 App Swift 檔已做語法解析，但沒有 Apple SDK 的型別檢查、SwiftUI render、iPhone 17 Pro 截圖、VoiceOver 或背景音訊實機結果。GitHub CLI 授權失效、連接器無首次 dispatch，本次無 CI Run／IPA。

AVFoundation decode／聲學探針整合測試已放進 macOS 工作流程，但本次沒有 macOS 可執行它。雙 AVPlayer 的實際切換、輸出音量、耳機與中斷競態、歌詞動畫聽感仍未驗收；不能宣稱無感或樣本級無縫。

## 音源與品質

- 遠端首次點歌先完整下載才播放，沒有漸進式 HTTP 起播。對大型 FLAC 可能有明顯等待；畫面顯示下載狀態，可換曲取消。
- WebDAV 支援 HTTPS、Basic 認證與有效系統信任憑證；不接受 HTTP、自簽憑證繞過、OAuth／Digest-only 伺服器或重新導向。SMB 透過 Files 提供者匯入，沒有直接 SMB 串流。
- WebDAV 搜尋使用完整同步索引；更新是完整目錄掃描，沒有 sync-token 增量同步。HTTP 外掛依其 catalog 分頁協定完成整份集合再更新。
- 快取沒有 ETag 自動更新、配額淘汰或管理介面；伺服器在相同來源 ID 下換檔後，既有快取可能保留舊內容。移除來源不會自動清除所有既存曲目與快取；存取失效會明確報錯。
- 私人登入資料使用 Keychain；支援的是本專案明確定義的外掛協定，不宣稱所有既有 Layz／Archive 外掛可原封不動使用。
- 沒有 YouTube Music、JioSaavn、Spotify 或 Apple Music 商業曲庫整合。未配置其服務授權、訂閱及可供此 AVPlayer 管線使用的原始音訊；沒有繞過 DRM 或私密取流。可用替代為自有 WebDAV、合法 HTTPS 外掛與 Files 音檔。
- 聲學比對只抽取三段 PCM，使用版本 ID、長度差不超過 120ms、最低相關 0.94 與一致時間偏移作保守門檻，並非完整錄音鑑識。不同母帶或有編碼偏移的相同歌曲可能被拒絕；每次最多六候選。
- AVPlayer 增益只能衰減；沒有可保證樣本級混音的底層 DSP 引擎。實際輸出位元深度、bit-perfect、外接 DAC 工作模式若系統無法提供就顯示未知。
- 一般本機檔案沒有跨來源通用錄音 ID；可由使用者連結另一版本並作聲學驗證，不會只憑同名自動替換。

## 資料、介面與歌詞

- SQLite 編碼與寫入在背景，但啟動仍同步讀取一次完整本機索引；長年聆聽事件全數保留記憶體，未做無限規模分頁。1,000 首持久化測試通過不代表所有 iPhone 大型庫效能已量測。
- SQLite 0.75 秒寫入合併窗口及播放器進度保存週期在強制終止時仍可能遺失最近片段；沒有跨裝置自動同步。
- 播放佇列是啟動當次的歌單快照；歌單之後新增／移除曲目，不立即重排正在播放的一輪。曲目從音樂庫刪除會清理佇列。
- 備份包含本機歌曲／封面／索引，不包含來源登入配置與網路快取。還原後重新新增來源會有新來源 ID，需要重新同步遠端曲目；既有遠端歌單引用尚無自動重綁。還原前資料庫與舊音檔保留，沒有自動回收介面。
- 翻譯可匯入使用者提供的繁體中文逐行文字／LRC；沒有自動翻譯模型或服務。歌詞解析不是所有廠商私有逐字格式的通用轉換器。
- 動態背景是本機封面取色流動漸層，沒有商業動態封面影片；鎖定畫面使用標準 MediaPlayer 控制與靜態封面。
- 公開原創測試來源固定引用 `feat/chaimusic-first-build` 分支；刪除分支或 GitHub raw 限流時需改為自架部署。它只有測試錄音，不能替代商業音樂曲庫。

一般編譯／邊界問題可交由 High／Medium；漸進串流管線、增量同步、快取管理、跨來源身份服務、樣本級音訊引擎、跨裝置同步屬新設計或主要功能，需回交 Ultra，不能當作小 Bug 清單。
